# Divine Interior 

**Divine Interior** is a modern interior design web application built to showcase interior design services, projects, and solutions. The project contains separate frontend and backend directories for organized development.

## 📁 Project Structure

```text
Divine_interio/
│
├── backend/
│   └── Backend source code
│
├── frontend/
│   └── Frontend source code
│
└── README.md
```

## 🛠️ Tech Stack

### Frontend
- Next.js
- JavaScript
- Tailwind CSS
- HTML5 & CSS3

### Backend
- Node.js
- Express.js
- MySQL
- REST APIs

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Ankitamishra17/Divine_interio.git
```

### 2. Navigate to the Project

```bash
cd Divine_interio
```

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

### 4. Setup Backend

Open another terminal:

```bash
cd backend
npm install
```

Configure your environment variables in the `.env` file and run the backend using the development script configured in `package.json`.

## ⚙️ Environment Variables

Create a `.env` file inside the relevant application directory and configure the required environment variables.

**Note:** Never commit sensitive credentials, API keys, or database passwords to GitHub.
